SwiiftXML

Browse XML files of any size, one row at a time.

Press ? for keyboard shortcuts

XML


  






  

    
    
Keyboard shortcuts

    

      
Rows

      
N / PNext / previous row (works everywhere)

      
↓ ↑Next / previous row (in the row list)

      
Page Down Page UpJump a page of rows

      
GGo to a row number

      
TabSwitch between the row list and the tree

      
Tree

      
↓ ↑Move to the next / previous node

      
→Open the node, or go to its first child

      
←Close the node, or go to its parent

      
Enter / SpaceOpen / close the node

      
* / -Expand everything below the node / collapse all

      
XShow the XML of the selected node

      
Right-click / Shift+F10Menu with Sum, Count and Group by for the node

      
Search

      
Ctrl+F or /Search the whole file

      
Enter / F3Find the next match

      
EscStop searching / close dialogs

    

    
Opened and closed nodes are remembered, so when you move to the next row
      the same parts of the tree stay open and the same field stays selected.

    
To summarize, right-click a field (for example Duration) and choose Sum or Count.
      In the window that opens you can group the result by one or more fields, for example ClientNumber
      + EmployeeNumber.

    
Search looks through the raw XML text, so you can also search for tags such as <Status>.
